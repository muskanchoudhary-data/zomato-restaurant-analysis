# 🍽️ Zomato Restaurant Analysis

## 📌 Project Overview
This project performs Exploratory Data Analysis (EDA) on Bangalore Zomato restaurant data using Python.

The objective is to identify restaurant trends, customer preferences, pricing patterns, and business insights.

---

## 🛠 Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook
- Git & GitHub

---

## 📊 Analysis Performed

### Data Cleaning
- Missing value handling
- Data type conversion
- Duplicate checking

### Exploratory Data Analysis
- Top rated locations
- Most popular cuisines
- Restaurant type analysis
- Online order vs rating
- Table booking vs rating
- Votes vs rating correlation
- Cost vs rating relationship
- Most expensive locations

---

## 📈 Key Insights

- Restaurants offering table booking have significantly higher ratings.
- Online ordering restaurants receive more votes on average.
- North Indian cuisine dominates Bangalore's restaurant market.
- Premium locations like Lavelle Road and MG Road have higher dining costs.
- Votes and ratings show a moderate positive correlation.
